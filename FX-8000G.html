A QUICK TRIP BACK TO 1986
Start here.

        
  1. Do a calculation.
    Press AC, type 2+2, and press EXE (Enter). The result is 4. Use a period as the decimal separator.
  2. Try a program.
    In the editor, click Send to calculator, then Run P0. The sum from 1 to 10 is 55. The library has more examples, including 3D Maze under Games.
  3. Respond to the calculator.
    When ? appears, enter a value and press EXE. The – Disp – indicator means you need to press EXE to continue. AC stops the program.
  4. Save your session.
    A session includes memory and the display. Export a copy to continue in another browser. An .fxp file saves only the text in the editor.

Editor syntax
This Casio uses commands such as Lbl, Goto, Isz, and Dsz. Programs have no line numbers. The editor converts text into keystrokes; the interpreter runs in the ROM.
Supported commands include sin cos tan log ln sqrt Abs Int Frac pi Ran# Rnd and Range Graph Y= Plot Line Cls Prog, along with comparisons = != < > <= >=, variables A–Z, Ans, quotation marks, and array indices [ ]. Follow the capitalization shown in the examples. EXP enters a base-10 exponent; ^ raises a value to a power.
Characters are validated before a transfer starts. You can stop a transfer and use “Undo transfer” to recover the previous state. The calculator still has its original memory limits.

        
About this implementation and references
Vanilla JavaScript, NEC μPD1007 / NM320 CPU, 8 KiB of RAM, and an HD44352 LCD controller. Calculations and programs run on the ROMs. The workspace design follows the TI-74 project.
Technical foundation: research and emulator v13 by Piotr Piatek. ROMs and character data come from the reference archive. The internal ROM was reconstructed and includes the corrections documented by its author.
Experimental version: timing is approximate. The FA-80 interface, printer, and cassette are not included. Known limitations of the ROM reconstruction and some instructions still apply. Not all functions have been verified against a physical calculator.
